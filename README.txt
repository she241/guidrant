GUIDRENT WEB APP PROTOTYPE

Open index.html in a modern browser.

Included:
- Mobile-first responsive UI
- 12 public Accra listing examples with source links
- Search, sort and filters
- Saved homes stored in browser local storage
- Compare up to three homes
- Property detail galleries
- Tour and agent-contact forms
- Seeker, agent and property profile forms
- Neighbourhood map-style discovery
- Safety and source disclosures
- PWA icon and manifest assets

Important:
This is a front-end prototype. Real launch requires authentication, database, storage, moderation, verification, notifications and legal/privacy review. Public listing data must be refreshed and permission/licensing reviewed before commercial republication.
