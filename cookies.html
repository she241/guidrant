Cookie and Storage Notice

Essential browser storage and optional analytics choices.

Draft effective date: 27 July 2026 · Owner details to complete before launch: legal entity name, registered address, support email and privacy contact.

1. Essential storage

Guidrent uses browser storage and authentication tokens needed to keep users signed in, remember saved homes, preserve security preferences and support the application. Disabling essential storage may prevent account features from working.

2. Optional analytics

The packaged website keeps optional analytics disabled until a user accepts them. No analytics provider is configured. If one is later added, update this notice with the provider, information collected, retention period, international transfers and opt-out controls.

3. Current local-storage keys

  • guidrentSaved for browser-only saved properties in demo mode.
  • guidrentCookieChoiceV1 for the user’s privacy choice.
  • Supabase authentication storage after the production backend is configured.

4. Changing your choice

Clear the site’s browser storage to reset the cookie banner. A production preferences panel should be added if non-essential advertising or measurement tools are enabled.
